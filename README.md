Profile Card Component

A small, accessible, responsive Profile Card built with **HTML, CSS, and Vanilla JavaScript**.
  
 [Live Project on GitHub Pages](https://authority0452.github.io/Profile-Card1/)

 Features
- Semantic, accessible HTML
- Responsive layout (mobile → desktop)
- Real-time timestamp using `Date.now()`
- Styled with modern gradients, soft shadows, and animations
- All elements tagged with `data-testid` for automated testing

 Tech Stack
HTML5
CSS3 (Flexbox + media queries)**
Vanilla JS**
